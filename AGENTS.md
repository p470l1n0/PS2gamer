# Instruções do projeto

- Ao concluir alterações neste projeto, salve-as no GitHub em `p470l1n0/PS2gamer`.
- Use o repositório conectado do GitHub para registrar as alterações e confirme que a gravação terminou.
- Nunca envie arquivos de BIOS, ISOs, ROMs ou outros arquivos de jogos.
- Não use o repositório `p470l1n0/ditadurabrasileira`; ele é de outro projeto.
- Se o acesso ao repositório não estiver disponível, avise que o salvamento automático falhou e não alegue que houve envio.
