# PS2gamer

Site em português para organizar jogos de PlayStation 2 e iniciar o PCSX2 instalado no Windows.

## Arquivos

- `index.html`: catálogo de jogos.
- `jogo.html`: página de cada jogo.
- `Jogar-Guitar-Hero-no-PCSX2.cmd`: iniciador local do ISO de Guitar Hero Flash Back.

O site não inclui jogos nem BIOS. O iniciador espera o PCSX2 em `C:\pcsx2-v2.9.155-windows-x64-Qt` e o ISO em `C:\Jogos\Guitar Hero Flash Back.iso`. Ajuste os caminhos no arquivo `.cmd` se a instalação estiver em outro local. O PCSX2 é um aplicativo Windows; o navegador não executa o emulador dentro da página.

## Uso

Abra `index.html`, selecione Guitar Hero Flash Back, clique em **Play**, baixe o iniciador e abra o arquivo baixado. Os demais jogos ficam indisponíveis até que seus ISOs completos sejam configurados.
